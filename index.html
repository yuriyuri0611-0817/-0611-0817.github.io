Linuxとは??

Linuxとは、オープンソースとして公開されているOSの1つ。
利点としては

  • 1行のコマンド操作で操作可能
  • スクリプトを書いてから自動化
  • 操作を後から確認できる

と、いろいろなメリットがあり多くの人から使われている

パッケージ管理

パッケージ管理についてのコマンドについて

  • apt install パッケージ名(パッケージをインストール)
  • apt update(aptが管理するパッケージリストを更新)
  • apt upgrade(aptで管理しているすべてのパッケージをバージョンアップ)
  • apt install --only-upgrade パッケージ名(指定したパッケージだけをバージョンアップ)
  • apt remove パッケージ名(指定したパッケージを削除)

ディレクトリ移動

ディレクトリ移動についてのコマンドについて

  • pwd (今いるディレクトリを表示)
  • ls (ディレクトリ内のファイル・ディレクトリを表示)
  • ll (ディレクトリ内のファイル・ディレクトリの詳細を表示)

ファイルの種類とパーミッション

左から順に、

  • ファイルの種類とパーミッション
  • ハードリンクの数
  • 所有ユーザー名
  • 所有グループ名
  • ファイルサイズ(バイト)
  • 作成・更新された日時
  • ファイル名・ディレクトリ名

1個目の文字(ファイルの種類)

  • d: ディレクトリ
  • -: ファイル
  • l: シンボリックリンク(別ファイルへの参照を持つファイル)

それ以降の文字について

  • 2-4個目の文字 (所有ユーザーのパーミッション)
  • 5-7個目の文字 所有グループのパーミッション)
  • 8-10個目の文字 (その他のユーザーのパーミッション)

3つの文字は左から順に、読み取り→実行→読み取り許可を表している

それぞれの意味としては

  • r: 読み取りを許可
  • w: 書き込みを許可
  • x: 実行を許可

例えばdrwxr-xr-xというファイルがあった場合

  • 種類がディレクトリ
  • 所有ユーザーは読み取り・書き込み・実行を許可
  • 所有Gとその他ユーザーは読み取り・実行だけ許可

となっている

ハードリンクについて

ハードリンクとは別ファイルへの参照、特定のファイルに対して異なる名前を持ちたいときに使う

cdコマンドについて

cdコマンドとは、移動先のディレクトリパス

  • cd libと打つと、libディレクトリに移動する
  • cd .. と打つと1つ上のディレクトリに移動できる
  • cd ~ でホームディレクトリ
  • cd - で1つ前に戻る

ファイルの中身を表示

cat ファイル名 (ファイルの中身を表示)

ファイル・ディレクトリの作成

ファイル・ディレクトリの作成のコマンドについて

mkdir (ディレクトリの作成)
touch ファイルのパス (ファイルの作成)

ファイル・ディレクトリの移動

mv 移動対象のパス 移動先のパス(ファイルやディレクトリを移動)
ex) mv 2024_ccc.md 2024_ddd.md (2024_ccc.mdを2024_ddd.mdに変更)

ファイル・ディレクトリのコピー

cp コピー対象のパス コピー先のパス
ex) cp 2024_ddd.md ../ (2024_ddd.mdを1つ上のディレクトリに移動)

ファイル・ディレクトリの削除

rm 対象のファイルパス

圧縮・アーカイブ

なぜアーカイブ化するの??
⇒複数のファイルやディレクトリを1つのファイルにまとめ、管理や転送を容易にするため

gzip 対象のファイルパス
また、gzip -d 解凍対象のファイルパス (gzipで圧縮したファイルを解凍)、 tar -cvf アーカイブファイル名 対象のパス (アーカイブファイルの拡張子は.tar)
各英語について、

  • c: 新しいアーカイブを作成
  • v: 処理ファイルを表示
  • f: アーカイブファイル名を指定

ex) tar -cvf sub.tar sub (subをアーカイブしたsub.tarファイルを作成)

tar -xvf アーカイブファイルのパス (アーカイブファイルを展開)

tar -czvf アーカイブ・圧縮後のファイル名 対象のパス
ex) tar -czvf sub.tar.gz sub (subをアーカイブして圧縮してsub.tar.gzファイルを作成)

コマンド入力を楽にする操作

tabキーを押すと自動保管機能が働く

findキーについて

find 検索対象ディレクトリパス 検索表現 (対象のディレクトリから条件に合うファイル・ディレクトリを検索)

find 検索対象ディレクトリパス -name 名前 (指定した名前に一致するファイル・ディレクトリを検索)

ex) find /root -name aaa.txt (/root内でaaa.txtという名前のファイルを検索)

ex) find /root -name "*.txt" (/root内でファイル末尾が.txtのファイルを検索)

ex) find /usr -size +1M (/usr内で1MB以上のファイルを検索)

ex) find /usr -size -1k (/usr内で1kb以下のファイルを検索)

検索機能

grep 検索パターン 対象ファイルのパス (対象ファイルから検索パターンに会う行を表示)
ex) grep "banana" aaa.txt (aaa.txtに含まれる行を表示)
ex) grep -n "banana" aaa.txt (aaa.txtに含まれる行と行番号を表示)

grep -r 検索パターン 対象ディレクトリのパス (対象ディレクトリ内のファイルから検索パターンにあう行を表示)

grep -nr "banana" / root (/root内のファイルのbananaが含まれる行と行番号を表示)

文字や変数を出力

echo 文字・変数 (文字や変数を出力)

リダイレクト

リダイレクトとは??
あるWebページのアドレス（URL）にアクセスした訪問者を、自動的に別の新しいURLやページへ転送する仕組み

コマンド > ファイルパス (出力先を標準出力からファイルに変更)

ex) echo "$HOME" > output.txt (環境変数HOMEをoutput.txtに出力)

コマンド >> ファイルパス (出力先を標準出力からファイルに変更(追記))

ex) echo -e "$PATH\n$HOMENAME" >> output.txt (環境変数PATHとHOMENAMEを改行で区切ってoutput.txtに追記)

ex) cat output.txt > output_cat.txt (output_txtの中身をoutput_cat.txtに出力)

コマンド 2>ファイルパス (エラーや警告の出力先を標準エラー出力からファイルに変更)

ex) echo "AAA" 2> log.txt (存在しないコマンドechoのエラーをlog.txtに出力)

コマンド > ファイルパス 2>&1 (出力先を標準出力、標準エラー出力からファイルに変更)

パイプ

コマンド1| コマンド2| コマンド3| …
コマンド1の結果をコマンド2の入力に、コマンド2の結果をコマンド3の入力に

wc ファイルのパス (行数、単語数、バイト数を出力)

wc -l ファイルパス (行数を出力)

ex) find /root -name "*.txt" | wc -l (/root内の拡張子.txtのファイルが何個あるかを出力)
